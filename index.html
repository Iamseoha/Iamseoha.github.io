      02 / 실제 결과물

      완성된 서비스 화면으로 말합니다.

      03 / 일하는 방식

      문제 정의부터 운영 개선까지, 한 사이클을 책임집니다.

      서비스 기획자와 PM에게 필요한 역량을 말로 설명하지 않고, 실제 프로젝트의 결정과 결과로 보여드립니다.

      01 / 문제 정의

      요청 뒤에 있는 진짜 문제를 찾습니다

      사업 요구와 사용자 상황, 기술 제약을 함께 살펴 해결할 문제와 제외할 범위를 먼저 정합니다.

      02 / 제품 설계

      모호한 요구를 개발 가능한 기준으로 바꿉니다

      요구사항, IA, 정책, 상태값, 예외 처리와 화면 흐름을 연결해 개발과 디자인이 바로 실행할 수 있게 만듭니다.

      03 / 협업과 실행

      여러 직군의 언어를 하나의 목표로 맞춥니다

      개발, 디자인, 사업, 외부 파트너 사이에서 결정 기준과 일정, 산출물을 관리하며 프로젝트를 실제 결과까지 끌고 갑니다.

      04 / 검증과 개선

      출시 뒤의 문제까지 다시 기획합니다

      QA로 기획과 구현의 차이를 확인하고, 고객 요청과 운영 데이터를 다음 요구사항과 개선 과제로 연결합니다.
